Huawei / HarmonyOS: when you tap the APK, your phone may block it the first time. Tap 设置 in the dialog (or Settings → Apps → App management → [your browser] → Install unknown apps) and toggle it on, then re-open the file.
How to install (step-by-step)
  1. Tap Download & Install APK above. Your browser will save the file.
  2. Open your phone's Downloads folder (or the notification bar) and tap the APK.
  3. If Android asks "For your security, your phone is not allowed to install unknown apps from this source", tap Settings in that dialog.
  4. Toggle Allow from this source on for the browser you used to download.
  5. Go back and tap the APK again. Confirm Install.
  6. Open JimmyQrg Chat from your launcher.
